Detailed Description

A ROS action client node for sending navigation goals and monitoring robot status.

This node interfaces with the /reaching_goal action server to send goals, cancel them, retrieve feedback, and track the robot's movement using /odom messages. It also interacts with a custom service /get_last_target to store and retrieve the last target location.

Subscribes to:
/odom (Odometry messages)

Publishes to:
/robot_status (Custom RobotStatus messages)

Action Server:
/reaching_goal (PlanningAction)

Service Client:
/get_last_target (GetLastTarget)
