Action_Client Module

Module author: Shady

This node interfaces with the /reaching_goal action server to send goals, cancel them, retrieve feedback, and track the robot’s movement using /odom messages. It also interacts with a custom service /get_last_target to store and retrieve the last target location.

Subscribes to:

  • /odom (Odometry messages)

Publishes to:

  • /robot_status (Custom RobotStatus messages)

Action Server:

  • /reaching_goal (PlanningAction)

Service Client:

  • /get_last_target (GetLastTarget)

Service_Server Module

Module author: Shady

This node provides a ROS service /get_last_target, which allows other nodes to either set a new last target or retrieve the previously stored target coordinates.

Service Server:

  • /get_last_target (rt1_assignment2_p1.srv.GetLastTarget)

scripts.last_target_service.handle_last_target(req)[source]

Callback function for the /get_last_target service.

If set_target is True, updates the last target coordinates. Otherwise, returns the last stored coordinates.

Args: :param req: Service request containing set_target, x, and y :type req: rt1_assignment2_p1.srv.GetLastTargetRequest

Returns:

Response containing stored or updated coordinates

Return type:
